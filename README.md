## 🌌 项目缘起与愿景

在当下的互联网舆论场与现代社会生活中，“主义”无处不在：自由主义、威权主义、后现代主义、存在主义、加速主义、环保主义……然而在碎片化争吵中，各种“主义”往往沦为彼此攻讦的标签与符号。

任何一种“主义”都不是凭空诞生的教条，而是**人类在特定历史危机与精神困境面前所作出的严谨探索与哲学自救**。

**主义星图 (Isms Constellation)** 旨在构建一个沉浸式、交互式的人类思想图谱空间：
- 将冷冰冰的政治哲学概念具象化为宇宙深空的“璀璨星辰”；
- 用五种逻辑连线具象化思想之间的演化血脉与交锋辩证；
- 赋予每个主义通俗易懂的“危机起因”、“电梯演讲”、“核心纲领”、“经典名句”与“现实投射”。

## ✨ 核心特性

### 1. 🌌 天体物理动态星图 (Constellation Canvas)
- **高性能原生 Canvas 粒子动力学**：基于 Canvas 2D 物理粒子引擎，实时模拟星辰自转微动、引力排斥与光子脉冲流动。
- **五大多维思想连线**：
  - 🔷 **传承 / 演进 (Evolution)**：母体学说的分支延展（如启蒙自由主义 ➔ 古典自由主义）。
  - 🔴 **对立 / 批判 (Opposition)**：思想阵营的正面抗衡（如经验主义 ⚔️ 理性主义、资本主义 ⚔️ 科学社会主义）。
  - 🟡 **催生 / 反拨 (Catalyst)**：历史危机与思潮倒逼激发的质变（如绝对理性之极 ➔ 浪漫主义狂飙）。
  - 🟢 **融合 / 交汇 (Fusion)**：兼采众长的跨界综合（如法兰克福学派对马克思主义与精神分析的融合）。
  - 🟣 **辩证 / 呼应 (Dialectical)**：跨越时空的螺旋式辩证统一与现代呼应。
- **智能交互焦点锁定**：选中某个星辰后，星图自动将视界聚焦于该流派及其直接思想脉络，排除无关干扰；拖拽画布畅快漫游不中断详情研读。

### 2. ⏳ 历史演化长河 (Historical Timeline River)
- **五大宏大纪元全景梳理**：
  1. **古代与古典源流** (公元前300年 - 公元1500年)：城邦政治哲学、自然神圣秩序与沉思德性。
  2. **理性与启蒙曙光** (17世纪 - 18世纪末)：科学革命、社会契约与近代资本主义萌芽。
  3. **工业狂飙与大革命时代** (19世纪)：大工业异化、阶级斗争、浪漫主义反叛与虚无深渊。
  4. **两次大战与冷战争锋** (20世纪前半至中叶)：极权反思、存在主义抉择与福利国家实践。
  5. **后现代与数字智能时代** (1970年至今 - 2026+)：宏大叙事解体、气候焦虑与硅基AI奇点狂想。
- **实时全局搜索与平滑定位**：支持按中文名、英文名、代表思想家及核心纲领即时筛选，并带有金光呼吸动效与平滑滚动定位（`scrollIntoView`）。

### 3. 🧭 哲学价值二维罗盘 (Value Compass)
- **三大坐标维度自由切换**：
  - **经典政治经济罗盘**：横轴（经济制度：公有共济 ↔ 自由市场） × 纵轴（政治公权：国家集权 ↔ 个人自治）。
  - **社会文化观念谱系**：横轴（经济所有制） × 纵轴（文化立场：秩序传统 ↔ 激进解构）。
  - **自由公权与多元罗盘**：横轴（政治公权边界） × 纵轴（存在多元度与自决度）。
- **标杆精简 / 全景双模式**：提供默认 40 派核心标杆视图，彻底解决 300+ 节点拥挤重叠问题，支持一键切换全量谱系。
- **象限聚焦与物理防碰撞算法**：第一至第四象限单独下钻缩放，内置微哈希抖动与物理斥力迭代排布，坐标重合流派智能错落平铺。

### 4. 📖 深度主义档案抽屉 (Ism Detail Dossier)
- **历史危机溯源**：阐明流派诞生的时代痛点（如“面对工业革命初期的无情剥削与工人异化……”）。
- **一句话电梯演讲**：30秒读懂其核心精髓。
- **核心纲领与论点清单**：提炼最具代表性的 3~5 条思想支柱。
- **经典名句与思想大师**：汇聚思想家肖像级格言与代表著作。
- **现实投射与现代争议**：剖析其在 21 世纪现实政策、科技伦理或社会思潮中的映射。
- **思想传承网络图谱**：直接点击卡片上的前驱/后继流派，在星图中连贯跃迁。

### 5. ⚖️ 思想思辨对决 (Dialectic Comparison)
- 支持任意两个意识形态之间的并排横向透视；
- 从形而上学假设、认识论进路、人性论假设、社会分配与自由主张五个维度进行深度剖析。

### 6. 🔮 哲学精神共鸣测试 (Resonance Quiz)
- 趣味且严肃的 10 道思想情境问答；
- 基于你的伦理、认知与社会选择，为你匹配契合度最高的意识形态灵魂星座。

### 7. 🎵 沉浸式思辨氛围伴奏 (Ambient Soundscape)
- 内置 Web Audio 合成器引擎，提供静谧冥想与宇宙深空频率的免版权原创环境音，助力深度研读。

## 📊 数据架构与流派规模

本项目包含详实考证的 **310+ 个思想流派节点** 与 **148 条高信度思想关联**，涵盖以下主要流派族系：

```
src/data/
├── categories.ts         # 八大流派大类定义 (政治意识形态/认识论/伦理学/美学/社会学等)
├── ismsData.ts           # 汇总导出入口与综合检索
├── quizQuestions.ts      # 哲学共鸣测试题库与权重计算矩阵
├── relationships.ts      # 148 条经脉络考证的思想演进、对立、催生、融合关系网络
└── isms/
    ├── vol1.ts           # 卷一：古典哲学、理知觉醒与理性主义源流 (1~40)
    ├── vol2.ts           # 卷二：政治哲学基础、近代自由主义与保守主义宪政 (41~80)
    ├── vol3.ts           # 卷三：社会主义运动、马克思主义谱系与无政府主义 (81~120)
    ├── vol4.ts           # 卷四：存在主义危机、虚无深渊与现象学体验 (121~160)
    ├── vol5.ts           # 卷五：心理学流派、语言转向与分析/科学哲学 (161~200)
    ├── vol6.ts           # 卷六：后现代主义、批判理论与解构前卫 (201~240)
    ├── vol7.ts           # 卷七：生态主义、女性主义、后殖民与东方现代思潮 (241~275)
    ├── vol8.ts           # 卷八：控制论、超人类主义、有效利他与硅基加速主义 (276~294)
    └── vol_extensions.ts # 拓展卷：存在主义/虚无主义/社民/自由意志细分纵深子流派 (295~310+)
```

## 🛠️ 技术选型与架构

- **前端核心**：React 19 + TypeScript + Vite 8
- **样式系统**：Tailwind CSS v4 (采用现代化 `@import "tailwindcss";` 原生指令)
- **动效与图标**：Lucide React + Motion (Framer Motion Next) + Canvas-Confetti
- **星图引擎**：HTML5 Canvas 物理引擎（粒子引力模拟、光子脉冲轨迹、防碰撞布局）
- **服务端支撑**：Node.js Express + TSX（支持全栈同构中间件与 API 扩展）

## 🚀 本地运行与开发

### 环境要求
- **Node.js** >= 18.0.0 (推荐 Node 20+)
- **包管理器**：npm / pnpm / yarn / bun 均可

### 1. 克隆仓库
```bash
git clone https://github.com/your-username/isms-constellation.git
cd isms-constellation
```

### 2. 安装依赖
```bash
npm install
# 或者使用 pnpm
# pnpm install
# 或者使用 bun
# bun install
```

### 3. 启动开发服务器
```bash
npm run dev
```
打开浏览器访问 [http://localhost:3000](http://localhost:3000) 即可开始探索思想星图。

### 4. 生产环境构建与打包
```bash
npm run build
```
构建产物将输出在 `dist/` 目录下。

### 5. 代码质量与类型检查
```bash
npm run lint
```

## ⌨️ 快捷交互说明

- **搜索任意流派**：在顶栏搜索框中输入中文或英文关键词（如 `存在`、`Sartre`、`自由`、`AI`），即时弹出模糊匹配预览，支持键盘上下键选择并回车跳转。
- **全景视角重置**：星图右下角点击 `全景重置` 或 `+/-` 按钮缩放画布。
- **思辨对决**：在任何流派详情页中点击“与其它主义辩证对比”，自由选择对手流派进入横向辩论场。
- **哲学灵魂测验**：点击顶栏“哲学共鸣测验”，10 题测出你的精神星座归属。

## 🤝 参与贡献

我们极其欢迎对人类思想历史抱有热情的朋友共同完善主义星图：
1. **纠错与校订**：若发现某主流思想家的代表作、核心论断或年代坐标存在史实偏颇，欢迎提交 Issue 或 PR。
2. **扩充关系图谱**：提出新的“对立”、“传承”或“融合”关系链条（请附带简要哲学史依据说明）。
3. **补充边缘/前沿流派**：随着技术演进（如加速主义、生机主义、数字游民意识形态等），欢迎扩充新的主义节点。

提交规范：
- 请确保新增节点遵循 `src/types/ism.ts` 的 `IsmNode` 接口规范。
- 提交前请运行 `npm run lint` 与 `npm run build` 确保无任何语法及构建错误。
