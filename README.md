## 🌌 项目缘起与愿景

在当下的互联网舆论场与现代社会生活中，“主义”无处不在：自由主义、威权主义、后现代主义、存在主义、加速主义、环保主义……然而在碎片化争吵中，各种“主义”往往沦为彼此攻讦的标签与符号。

任何一种“主义”都不是凭空诞生的教条，而是**人类在特定历史危机与精神困境面前所作出的严谨探索与哲学自救**。

**主义星图 (Isms Constellation)** 旨在构建一个沉浸式、交互式的人类思想图谱空间：
- 将冷冰冰的政治哲学概念具象化为宇宙深空的“璀璨星辰”；
- 依据大众对各流派的历史文化“刻板印象”进行专属配色（赤红社会主义、金黄资本主义、森林绿生态主义、皇家藏青保守主义、霓虹青数字加速主义等）；
- 用五种逻辑连线具象化思想之间的演化血脉与交锋辩证；
- 赋予每个主义通俗易懂的“危机起因”、“电梯演讲”、“核心纲领”、“经典名句”与“现实投射”。

## ✨ 核心特性

### 1. 🌌 天体物理动态星图 (Constellation Canvas)
- **高性能原生 Canvas 粒子动力学**：基于 Canvas 2D 物理粒子引擎，视口裁剪（Frustum Culling）大幅降低开销，锁定 60 FPS 丝滑顺畅。
- **空间松弛防重叠算法**：确保任意两颗星辰之间间距保持在 135px 以上，消除重叠遮挡。
- **0.3s 悬停防晃眼延迟**：鼠标滑过星辰时不突兀跳弹窗，停留满 300ms 才会优雅浮现情报卡片，守护注意力。
- **航天级平滑聚焦漫游**：详情页点击其他主义时，镜头自适应抽屉宽度，以 750ms 奢华缓动平滑居中至视口中央。
- **五大多维思想连线**：
  - 🔷 **传承 / 演进 (Evolution)**：母体学说的分支延展（如启蒙自由主义 ➔ 古典自由主义）。
  - 🔴 **对立 / 批判 (Opposition)**：思想阵营的正面抗衡（如经验主义 ⚔️ 理性主义、资本主义 ⚔️ 科学社会主义）。
  - 🟡 **催生 / 反拨 (Catalyst)**：历史危机与思潮倒逼激发的质变（如绝对理性之极 ➔ 浪漫主义狂飙）。
  - 🟢 **融合 / 交汇 (Fusion)**：兼采众长的跨界综合（如法兰克福学派对马克思主义与精神分析的融合）。

## 🚀 本地部署与运行开发

### 环境要求
- **Node.js** >= 18.0.0 (推荐 Node 20+)
- **包管理器**：`npm` / `pnpm` / `yarn` / `bun` 均可

### 1. 克隆代码仓库
```bash
git clone https://github.com/your-username/isms-constellation.git
cd isms-constellation
```

### 2. 安装项目依赖
```bash
npm install
# 或者使用 pnpm
# pnpm install
# 或者使用 bun
# bun install
```

### 3. 启动本地开发服务
```bash
npm run dev
```
启动后终端将输出访问地址，打开浏览器访问 [http://localhost:3000](http://localhost:3000) 即可开始探索思想星图。

### 4. 生产环境构建打包
```bash
npm run build
```
打包输出目录为 `dist/`，产物为纯静态资源，可直接部署于 GitHub Pages、Vercel、Cloudflare Pages 等静态托管平台。

### 5. 生产全栈启动 (含云端 AI 音乐路由)
```bash
npm run start
```

### 6. 代码质量与类型校验
```bash
npm run lint
```
